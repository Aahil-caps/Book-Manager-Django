# Book Manager Django

A simple Book Manager web application built using Django.

This project was created as a practice project to learn and understand Django basics, models, ORM, templates, views, URLs, and database operations.

## Features

- Add a new book
- View all books
- Sort books by published date
- Validate empty book title
- Store book details in database
- Simple book management interface

## Technologies Used

- Python
- Django
- HTML
- CSS
- SQLite

## Book Details

Each book contains:

- Title
- Author
- Price
- Published Date
- Availability
